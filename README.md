## PeerShare: File Transfer Application

PeerShare is a full-stack peer-to-peer file transfer application that combines a custom Java backend with a Next.js frontend. Includes HTTP server implementation with multi-threaded socket programming to handle concurrent file transfers from multiple clients. The backend uses custom request parsing, CORS handling, and upload/download logic for robust file operations.
